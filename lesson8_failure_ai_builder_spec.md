# Lesson 8 — "Failure and Recovery" — AI Builder Specification

**Program:** Strong Heart, Wise Mind — Quranic Life Skills for Muslim Kids
**Age:** 10–13 · **Format:** standalone `lesson8.html` (iframe-loaded, same 8-section pattern as lessons 1–3)
**Core rule:** One fall is news — not a nationality.
**Main tool:** The Comeback Plan: Feel — Learn — Smaller — Trust

## Learning goal
A story-centered Islamic SEL lesson that teaches children how to lose — an exam, a tryout, a match — without losing themselves, and to get back up with an honest heart, one specific lesson, and trust in Allah.

## Sections
1. Main story: Main Story: Taha and the Tryout (MCQ checkpoints inside)
2. Quran anchor + balance card
3. Prophetic lens (verified hadiths below)
4. Understand the difference — Signal / Unhelpful thought / Wise choice + Do-not-teach warning
5. Main SEL tool: The Comeback Plan (4 skill cards) + interactive The Falling Scale
6. Transfer practice: Transfer Practice: Hafsa and the Test Paper
7. Home challenge: My Comeback Notebook
8. Parent/Teacher guide: Put the Comeback Plan in Order ordering game + scenario checkpoint
